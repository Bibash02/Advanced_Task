
# Basic File Encryption/Decryption
A Python-based application that allows users to secure text files by encrypting and decrypting them using Fernet symmetric encryption. 
This project demonstrates basic cryptography concepts, file handling, and secure data storage in Python.

🛠 Technologies Used

Python 3

cryptography (Fernet)

Built-in Python modules: os

🔐 Encryption Algorithm

This project uses Fernet encryption, which:

Is a symmetric encryption algorithm

Uses a single secret key for both encryption and decryption

Ensures data confidentiality and integrity

# N-Queens Problem
The N-Queens problem aims to place N queens on an N × N chessboard so that no two queens attack each other (same row, column, or diagonal).

This project solves the problem using the backtracking algorithm in Python.

🎯 Objectives

Represent the chessboard using a 2D array

Use backtracking to place queens safely

Ensure no two queens share the same row, column, or diagonal

🛠️ Tech Stack

Python 3

Backtracking Algorithm
